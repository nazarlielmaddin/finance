# Финансовый раздел Appina — пакет для доработки

Что внутри: весь код финансового раздела (сервер + интерфейс), структура базы
и подсказки по устройству. **Данных и паролей в пакете нет** — ни `.env`,
ни боевой базы с цифрами.

## Устройство

    server/routes/finance.js        весь API раздела (HTTP-ручки)
    server/lib/finance-db.js        подключение к data/finance.db и помощники
    server/lib/finance-claude.js    финансовый ИИ-помощник (анализ и ответы)
    server/lib/finance-digest.js    ежедневная сводка
    server/middleware/*             авторизация, права, обработка ошибок
    server/lib/access.js            кто видит раздел (см. ниже)
    client/src/pages/Finance.jsx    весь интерфейс раздела (одна страница)
    client/src/components/ui.jsx    общие элементы (кнопки, поля, таблицы)
    db/finance-schema.sql           структура финансовой базы, без данных

## Как это работает

* Отдельная база: `data/finance.db` (SQLite). Задачи и сотрудники живут в другой
  базе (`tasq.db`) — финансовая с ней не смешивается.
* Доступ к разделу **не даёт роль**. Его видит только `developer` и те, кому
  явно выставлен флаг `finance_access` (админка → Пользователи).
  Внутри раздела есть подразделы, они перечислены в `access.js` →
  `FINANCE_SECTIONS`.
* Интерфейс — одна страница `Finance.jsx`, разделы переключаются вкладками.
  Стили — общие токены приложения, отдельной темы у раздела нет.

## Что нужно для локального запуска

1. Node.js 22+.
2. Положить пакет рядом с исходным проектом Appina либо запросить у нас полную
   копию репозитория — здесь только файлы раздела, без сборки и зависимостей.
3. Создать свою `data/finance.db` из `db/finance-schema.sql`:

       sqlite3 data/finance.db < db/finance-schema.sql

4. Запуск приложения: `npm install`, затем `npm run dev` в корне проекта.

## Правила при доработке

* Не переносить финансовые данные в `tasq.db` и наоборот.
* Любой новый подраздел добавлять в `FINANCE_SECTIONS` (`server/lib/access.js`),
  иначе он не будет виден в матрице доступов.
* Все суммы считать на сервере; интерфейс только показывает.
* Ключи и пароли — только через `.env`, в коде их быть не должно.
